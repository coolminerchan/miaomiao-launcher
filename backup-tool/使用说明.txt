开放空间 Windows 备份工具包

适合想保存自己官服角色进度、背包、染色或家园的玩家。每个人在自己的电脑上用自己的账号跑一遍，结果保存在本机。Windows 10/11 x64，使用原有的国服 PC 客户端。工具已带便携 Python、TShark 与解析依赖，抓包用 Windows 自带的 PktMon。

一、备份自己的账号

1. 在资源管理器「全部解压」到你能写入的目录，例如 D:\Games\OverField-Backup。先关闭本地私服代理或转发工具，让客户端照常连接官服。
2. 右键 1_backup_account.cmd，选择「以管理员身份运行」。看到「抓包已开始」后，退出并重新打开客户端，登录自己的官服账号，等角色进入场景。
3. 想保存哪些数据，就点开哪些界面并等内容加载。建议先看角色、穿搭及染色预设、背包、武器和装备、任务、宠物、个人资料、好友、邮件、抽卡历史、成就与图鉴。抽卡历史和邮件有多页时，打开你想留存的页和详细内容。
4. 进自己的家园等家具加载。若要留存多套布局，分别切到对应预设并进入家园。需要逐套独立归档时，每套单独运行并给输出目录备注。
5. 回到备份窗口按回车。到 output\account_日期时间\export\summary.json 核对。player_highlights 应有你的 UID 和角色数量，message_counts 应出现你关心的响应。宠物看 GetPetRsp，家园实际布局看 SceneDataNotice。缺哪项就重新抓一次，打开对应界面。

二、只备份拜访过的家园

1. 右键 2_backup_gardens.cmd，以管理员身份运行。已经登录官服的话可以直接拜访。
2. 依次进入想保存的好友家园，每家等家具显示出来再离开。按回车结束。
3. 在 output\gardens_日期时间\export 内查看 gardens_index.json，以及按 UID 保存的 .bin 和 .json。每位屋主保留家具数量最多的一份，数量一样时取抓包中较晚的一份。昵称无法从场景取得时按 UID 核对。

三、保存和重新解析

建议把自己的 output 额外复制到安全的硬盘目录。每次备份各有一个目录，内含 capture.etl、capture.pcapng 和 export。export\json 可查看，export\raw 是账号数据的 Protobuf 二进制。抓包文件可能包含登录令牌、UID、地址和好友资料，请只保留在可信的位置。转发给朋友的是原始工具包 ZIP。导出跳过已知登录请求，并移除登录响应里的日志令牌，导出的玩家数据仍属于个人资料。

有旧 .pcapng 时可直接拖到 3_decode_pcap.cmd，输出会写在抓包旁边。重解包家园时，在工具包目录打开 PowerShell，运行下面的命令。

  .\tools\python\python.exe -B -X utf8 .\extract_gardens.py "D:\你的备份\capture.pcapng"

四、核对和排查

- 已连官服且重新登录，summary.json 仍没有 UID 时，检查当时是否确实进到场景，是否开着本地服代理，以及工具是否收到游戏端口流量。默认抓取 TCP 11001–11004、21001、21002，来自现有国服 PC 记录与脚本配置。客户端或区服改端口时，需要按实际情况调整。
- 只出现部分数据时，针对缺项再做一次完整登录与界面加载。客户端收到过的数据才会出现在备份里。
- 出现未知消息 ID 时请保留原始抓包，后续可换更新的协议重新解析。本包用工作区已经验证过的协议定义。
- 如果 TShark 无法启动或 Windows 提示缺少 MSVCP140.dll / VCRUNTIME140.dll，运行 tools\vc_redist.x64.exe 安装 Microsoft Visual C++ x64 运行库，再重试。
- 工具提示 PktMon 已经运行或已有筛选器时，先到原来的诊断或备份窗口正常结束该会话，再重新运行本工具。
- 这份工具包用于备份归档。将归档导进 of-ps 是后续独立步骤，依赖目标服务端的存档结构。
